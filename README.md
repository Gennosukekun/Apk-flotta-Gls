# Gestione Chiavi Mezzi - Android
App Android nativa collegata al backend Hatchable esistente. Nessuna WebView.

Include associazione autista al telefono, scanner QR nativo CameraX + ML Kit, presa/restituzione chiave, stato assegnazione e foto mezzo compresse prima del caricamento.

Il workflow GitHub Actions compila automaticamente l'APK debug a ogni push su main.
